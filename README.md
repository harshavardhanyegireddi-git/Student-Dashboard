
# 🎓 Student Dashboard

A modern, responsive Student Dashboard built using **HTML5 and CSS3 only**. This project provides a clean interface for students to view their academic information, attendance, grades, timetable, enrolled subjects, notifications, and college announcements.

## 🚀 Live Demo

[View Live Demo](YOUR_DEPLOYED_WEBSITE_URL)

## 📸 Project Overview

The Student Dashboard is designed to provide students with a centralized view of their academic activities through a clean, modern, and responsive interface.

## ✨ Features

- **Student Profile:** Displays student name, roll number, department, program, and semester.
- **Quick Statistics:** Shows total subjects, attendance percentage, GPA, and classes attended.
- **Attendance Overview:** Visual attendance progress circle with present, absent, and total class counts.
- **Marks & Grades:** Academic performance table with internal marks, external marks, total scores, and grades.
- **Weekly Timetable:** Displays the weekly class schedule with days and time slots.
- **Enrolled Subjects:** Subject cards with instructor names, course codes, and credits.
- **Notifications:** Displays important alerts, examination dates, fee reminders, and assignment deadlines.
- **Announcements:** Shows the latest college updates and academic announcements.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **CSS-only Navigation:** Mobile sidebar toggle implemented without JavaScript.

## 📱 Responsive Design

The dashboard supports different screen sizes:

- Desktop – Full sidebar and multi-column dashboard.
- Tablet – Adjusted grid layouts.
- Mobile – CSS-powered collapsible sidebar and single-column sections.
